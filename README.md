# Newsletter sign-up form with success message

![Design preview for the Newsletter sign-up form with success message challenge](./design/desktop-preview.jpg)

Solution to the Frontend Mentor **Newsletter sign-up form with success message** challenge - a responsive form built from the provided design.

**Live demo:** https://erfan-revenant.github.io/Front-Mentor-newsletter-sign-up-with-success-message/

## Built with

- Semantic HTML5
- CSS custom properties, Flexbox and media queries
- Vanilla JavaScript for the interactive behaviour (no framework, no build step)
- Bundled webfonts and SVG assets from the challenge starter files

## Run locally

```bash
git clone https://github.com/ErfanBagheri404/Front-Mentor-newsletter-sign-up-with-success-message.git
cd Front-Mentor-newsletter-sign-up-with-success-message
```

Open `index.html` in a browser. Nothing to install or compile.
